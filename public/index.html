How to link your WhatsApp

  1. Type your number above with the country code (Kenya: 254712345678, no + and no leading 0) and press Generate.
  2. On that phone open WhatsApp, then Settings, then Linked devices, then Link a device.
  3. Tap “Link with phone number instead” and type the 8-character code from this page.
  4. This page says “Access granted” and the bot messages you “connected successfully”.
  5. Send .menu in WhatsApp to see every command, or .ping to test it.

WhatsApp rejects the code?

  • Enter the code within about a minute. Generating a new code cancels the old one.
  • The number you typed here must be the number of the phone you are linking from.
  • Use “Link with phone number instead”, not the QR scanner.
  • Stop any other copy of the bot (Render, other terminals) before linking.
  • After many failed tries WhatsApp can pause linking for a few hours. Wait, then try once.

Commands not replying?

  • Start every command with the prefix (default .), for example .ping.
  • Run only one copy of the bot. If it also runs on Render or in another window, WhatsApp drops one of them.
  • Check the status at the top says BOT ONLINE. If not, check the terminal for errors.
  • Create the chat_settings table in Supabase (SQL in supabase/schema.sql) for welcome, antilink and auto settings.
  • Group commands need you or the bot to be a group admin.
