How to link a bot

1 · Add bot

Press “Add bot”, enter the WhatsApp number with country code (digits only, e.g. 254712345678), then press “Generate pairing code”.

2 · Open WhatsApp

On the phone you just entered, open WhatsApp, go to Settings → Linked devices → Link a device.

3 · Enter the code

Tap “Link with phone number instead”, type the code shown on screen, and the bot comes ONLINE.

4 · Done

Send .menu in WhatsApp to see what the bot can do. Repeat for each number you want to link.

Notes

  • One bot per WhatsApp number. Linking the same number twice makes WhatsApp kick the old one.
  • Enter the code within about a minute; generating a new code cancels the old one.
  • This node is read-only: you can see who is online and link bots, but cannot unlink or remove anyone else’s bot.
